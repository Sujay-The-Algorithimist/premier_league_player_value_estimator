# Image attribution

Phase 1 uses no external player images. Later phases may load rights-cleared files from `web/public/players/<slug>.webp`.

The cinematic home experience currently uses these supplied local files: `web/public/players/ftbl_video.mp4`, `Halland.png`, `Rooney.png`, `Rodri.png`, and `Ronaldo7.png`. Record the source, license, and author for each asset before publishing.
